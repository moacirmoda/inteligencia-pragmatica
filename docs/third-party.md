# Dependências e materiais de terceiros

## Dependências Python

- PyYAML — licença MIT — dependência de runtime para parsing seguro de YAML.
- pytest — licença MIT — dependência exclusiva de desenvolvimento e testes.
- Ruff — licença MIT — dependência exclusiva de desenvolvimento e lint.

As versões e hashes resolvidos estão registrados em `uv.lock`.

## Referências conceituais

O projeto é uma implementação independente inspirada no livro *Inteligência Pragmática*, de Max
Peters. Nenhum texto extraído ou arquivo do livro faz parte do repositório. Consulte `NOTICE`.

A arquitetura também tomou como referência princípios públicos do projeto Mirror Mind, sem copiar
código nem adicionar dependência do projeto.
