# Roteamento

Escolher **Definir** para PGG/4Cs, **Planejar** para PMV/8Rs, **Executar** para próxima sessão,
**Revisar** para feedback e plano travado, e **Completo** quando o usuário pede aplicação geral ou há um
estado existente a retomar.

Escolher profundidade:

- `light`: baixa consequência e reversível; TATT ou PMV parcial.
- `standard`: projeto relevante, impacto moderado; 8Rs.
- `deep`: alto impacto ou difícil reversão; 8Rs, premortem, referências múltiplas, Planos B e possível simulação.

Perguntar somente sobre a primeira lacuna que bloqueia a fase. Se uma pesquisa segura no contexto puder
respondê-la, pesquisar antes de perguntar. Nunca inferir prazo, dono, compromisso ou capacidade sem base.
