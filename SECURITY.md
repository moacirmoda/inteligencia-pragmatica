# Política de Segurança

## Versões suportadas

Enquanto o projeto estiver em `0.x`, somente a versão mais recente recebe correções de segurança.

## Relatando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades ainda não corrigidas. Use o recurso **Report a
vulnerability** na aba Security do repositório GitHub e inclua:

- descrição e impacto;
- passos mínimos para reprodução;
- versões e ambiente afetados;
- possível mitigação, se conhecida.

Espere uma confirmação inicial em até sete dias. Não inclua dados pessoais, objetivos privados,
credenciais ou conteúdo proprietário em relatórios.
